## 共享主机适合谁，不适合谁

个人博客、作品集、小型企业官网、落地页、流量不大的在线小店、学建站的练手项目，这些场景共享主机都够用。它的原理类似合租：一台物理服务器上住着几十个网站，CPU、内存、带宽大家分着用，成本因此压到每月几美元的水平，服务器维护、安全更新和备份则由服务商负责。

不适合的情况也有明确信号：网站频繁卡顿、后台动不动超时、投放广告后流量明显上涨、想跑 API 或后台管理这类额外服务。命中两条以上，就该看 VPS 了；至于大促期高并发的电商、游戏服、实时数据业务，直接考虑独立服务器，共享主机的资源模型扛不住。

## 写在条款里的限制，比价格更容易翻车

共享主机的坑很少直接写在价格表上。以下限制全部来自各家官网页面和条款的公开信息。

**Spaceship**
- CPU 和内存上限（1–4 核、1–3GB）属于“突发流量支持”，只在有限时间内生效，持续高占用会受限；
- “不限量磁盘”仅限 Supreme 档，且要按可接受使用政策（AUP）执行，当无限网盘用会被盯上；
- 文件数有硬上限：Essential 30 万个、Pro 50 万、Supreme 70 万；
- 服务器层面有 DDoS 防护，但条款注明不包含单个网站的保护，需要另购；
- 迁移完全自助：上传不超过 20GB 的 cPanel 备份包自己恢复，仅支持 MySQL/MariaDB，邮箱和 SSL 要手动配置。

**Hostinger**
- 免费域名只送 1 年，续费按正常价格收；
- Premium 档是每周备份，每日备份要从无限制档开始；
- Premium 每个网站送 2 个邮箱，免费期同样只有 1 年。

**InMotion Hosting**
- Launch 档只有聊天和工单支持，电话支持从 Power 档开始；
- 专用 IP、2 vCPU、4GB 内存是 Pro 档专属；
- 好的一面：迁移由官方团队操作、承诺零停机，Launch 档就包含。

**UltaHost**
- 入门版限 1 个域名、约 1 万月访问量，超了就要升档；
- 每日备份是全系标配，这一点比 Hostinger Premium 的每周备份厚道。

所有共享主机还共用一条规则：标“未计量”或“无限”的带宽，都受可接受使用政策约束，超出合理范围就会被限。真正的天花板通常是 CPU、内存和文件数，流量反而其次。

## 常见问题

**共享主机和 VPS 主机到底怎么选？**
流量小、预算有限、先把项目跑起来，共享主机就够。一旦开始投放、做 SEO，流量上来了，或者后台操作明显变慢，就该升 VPS——VPS 给你独立的 CPU、内存和 SSD，性能和稳定性都不在一个量级。

**共享主机能开网店吗？**
低到中等流量的小店可以起步，Hostinger 各档都标明支持电商，UltaHost 也把电商新手列在适用人群里。大促、秒杀这类高并发场景是另一回事，那是对 VPS 或独立服务器的需求。

**“无限流量”是真的无限吗？**
带宽普遍标“未计量”，但都受可接受使用政策约束。对你影响更直接的，是 CPU 核数、内存和文件数上限——Spaceship Essential 档的 30 万个文件、1GB 内存就是典型例子。

**买多长的周期划算？**
折扣基本绑长周期：Hostinger 最便宜的月价要求 48 个月付，UltaHost 的 $3.44/月按 24 个月计，Spaceship 的年付价也明显更低。各家都有 30 天左右的退款期兜底，趁折扣买长周期锁价是合理操作，前提是续费价你已经查清楚。
